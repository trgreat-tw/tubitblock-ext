# 手指心跳感測器 v1.2.0

只提供3個常用積木：初始化、讀取訊號值、估算BPM。程式自動採樣，不需要另外放「更新狀態」。

編號可自行輸入0或正整數，例如8、42、100；初始化和讀取使用相同編號。不同模組使用不同編號及接腳，數量依控制板資源而定。

| 訊號 | Arduino 預設 | ESP32 預設 |
| --- | --- | --- |
| S | A0 | GPIO15 |
| ＋ | 依模組，通常5V | 3.3V |
| －／GND | GND | GND |

~~~text
心跳模組（42）初始化訊號腳 A0
重複無限次
  使用「心跳模組 42 估算 BPM」
~~~

讀取訊號值統一為0～1023，初始化依目前控制板自動選ADC刻度。手指保持穩定並遮蔽環境光，系統在建立三個間隔相近的波峰後估算BPM。沒有穩定訊號時回傳0，超過2.5秒無波峰也回到0。這是學習用估算，不供醫療量測。

TubitBlock會在每輪主迴圈的repeat()中自動呼叫各編號的採樣程序；讀值本身只讀快取。避免長時間delay或阻塞迴圈，否則無法持續採樣。舊專案的波形、振幅、波峰與手動更新等進階積木保留載入相容，不再出現在工具箱。

資料：[Joy-IT KY-039](https://sensorkit.joy-it.net/en/sensors/ky-039)。

## 接線要點

ESP32 訊號維持3.3V。預設GPIO15屬經典ESP32的ADC2，搭配Wi-Fi時請改用板卡可用的ADC1腳位。GPIO0／2／5／12／15涉及啟動設定，接線以實際板卡與模組絲印為準。
