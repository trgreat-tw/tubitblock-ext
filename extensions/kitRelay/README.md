# 繼電器 v1.2.0

Arduino／ESP32共用，工具箱只保留兩個積木，不需要更新狀態。

1. **繼電器（編號）初始化**：設定訊號腳及高／低電位觸發；setup先寫入關閉電位，再設為輸出。
2. **繼電器（編號）開啟／關閉**：控制繼電器。

編號可直接輸入任意非負整數，例如0、8、42、100；同一顆模組的積木填相同編號。多顆使用不同編號與不同接腳。

| 接線 | Arduino預設 | ESP32預設 |
| --- | --- | --- |
| S／IN | D2 | GPIO23 |
| ＋／VCC | 依模組規格供電 | 依模組規格供電 |
| －／GND | GND | GND |

例如「繼電器8初始化訊號23觸發電位高電位」，接著使用「繼電器8開啟／關閉」。

KY-019常見為5V繼電器；線圈供電與控制邏輯是不同條件。ESP32需使用相容3.3V邏輯觸發的模組，或搭配適當驅動／電位轉換。以模組絲印接線，一般非隔離接法需共同GND。可先用低壓LED或小燈測試；上電到程式開始前的腳位狀態仍由硬體決定。

舊專案的控制狀態積木仍可載入，但不再列於工具箱。無第三方函式庫依賴。

資料：[KY-019官方資料](https://sensorkit.joy-it.net/en/sensors/ky-019)。實物照片以600×372 SVG畫布等比例顯示，原圖與來源SHA256保留於 assets/SOURCES.json。

## 專屬函式庫

擴充附帶 `TuKitRelay`，產生的程式只會 `#include <TuKitRelay.h>`，再宣告物件與呼叫方法；class與硬體處理函式均在函式庫內。保留 `lib/TuKitRelay` 完整資料夾即可編譯，無額外第三方函式庫依賴。
