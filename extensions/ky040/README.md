# 旋轉編碼器 v1.2.0

保留4個常用積木：初始化、讀取計數、讀取按鈕狀態、設定計數（填0就是歸零）。初始化中可選1倍／2倍／4倍計數，不用放「更新狀態」。

## 使用

編號是可自行輸入的非負整數，例如0、1、8、42。同一顆編碼器的初始化與讀值使用相同編號，不同顆使用不同編號與接腳。編號不再限制1～4；可接數量仍依實際可用接腳與記憶體而定。

| 訊號 | Arduino Uno | ESP32預設 |
| --- | --- | --- |
| CLK | D2 | 23 |
| DT | D3 | 15 |
| SW | D4 | 12 |
| ＋ | 5V | 3.3V |
| GND | GND | GND |

初始化一次，然後在「重複無限次」中直接讀取計數或按鈕。範例：編碼器8初始化後，讀取「編碼器8目前計數」；需要歸零時用「編碼器8設定計數為0」。

ESP32使用使用者指定的[AiEsp32RotaryEncoder](https://github.com/igorantolic/ai-esp32-rotary-encoder)函式庫，以CLK／DT中斷累計旋轉；關閉其預設加速，讓倍頻計數保持固定。按鈕沿用非阻塞去彈跳。

官方函式庫支援ESP32／ESP8266，並不支援AVR，因此一般Arduino控制板保留原本的輪詢後端。兩種後端都透過TubitBlock既有repeat()自動更新對外數值與按鈕，不需要新增更新積木。Arduino輪詢時，長時間等待或阻塞程式仍可能漏掉快速旋轉。

初始化可選倍頻，預設1倍以保留原本計數行為。同樣的旋轉距離，2倍與4倍會有較多計數；實體旋鈕每個卡點對應的訊號週期依模組而異。

| 倍頻 | 每個完整CLK／DT訊號週期的計數 | 每次計數所需有效訊號變化 |
| --- | --- | --- |
| 1倍（預設） | 1 | 4 |
| 2倍 | 2 | 2 |
| 4倍 | 4 | 1 |

沿用舊專案的TRANSITIONS欄位儲存每次計數所需的訊號變化次數，選單1／2／4倍分別儲存4／2／1；不要把倍頻值直接當成函式庫的第四參數。舊專案未設定該欄位時仍使用4（1倍）。Arduino與ESP32使用相同規則。

ESP32保留舊積木的正反方向定義；部分訊號與反轉時的細部計數由Ai函式庫解碼，與Arduino輪詢後端可能有差異。

## 隨附函式庫

產碼仍只include專屬的TuRotaryEncoder.h，不將class展開到程式碼。ESP32時轉接器才引入AiEsp32RotaryEncoder.h；Arduino時不引入或編譯Ai函式庫。

部署時保留整個lib/TuRotaryEncoder與lib/AiEsp32RotaryEncoder，後者採官方1.7、commit e6a33400276cf3cbd2389eca671eba8553f8fe03，來源未修改，LICENSE.md及UPSTREAM.json一併保留。不要在AVR編譯時強制編譯所有相鄰函式庫。

經典ESP32的0／2／5／12／15涉及啟動設定；若外接模組影響開機，依板卡規格改選適合的腳位。

## 既有專案

舊版進階積木仍可載入，但已從工具箱收起。舊專案若包含明確更新積木，該編號會沿用手動更新方式，避免重複採樣。
