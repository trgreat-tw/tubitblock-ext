# XY搖桿 v1.2.0

工具箱只保留三個常用積木：初始化、讀取X／Y軸、按鈕按住。Arduino預設X=A0、Y=A1、SW=D2；ESP32預設X=15、Y=12、SW=23。SW可選不使用。類比讀值保留控制板原始刻度（AVR通常0～1023，ESP32通常0～4095），不修改全域ADC解析度。

```text
搖桿 8 初始化 X A0 Y A1 按鈕 SW 2
重複無限次
  使用「搖桿 8 讀取 X 軸」
  如果「搖桿 8 按鈕按住？」
    執行你的動作
```

編號是可自行輸入的非負整數，例如0、8、42；同一模組的初始化與讀取使用相同編號，不同實物使用不同接腳。讀取會自行採樣，不需要另外放「更新狀態」。按鈕／接點開關內建20ms去彈跳，其他數位模組直接讀取；有去彈跳時請在迴圈持續讀取。

模組電源依實物規格接線，GND共地；ESP32訊號保持3.3V。ESP32預設從23、15、12、5、2、0選用；類比訊號使用15／12，23／5無ADC。經典ESP32的這些ADC2腳位與Wi-Fi共用資源，需要Wi-Fi時改用板卡可用的ADC1。GPIO0／2／5／12／15也涉及啟動設定，需配合實際板卡與模組外部電位。

舊版的更新、瞬間事件與進階讀值opcode仍保留供既有專案載入，已從工具箱收起。

## 專屬函式庫

此模組的實作位於 `lib/TuKitJoystick/src/TuKitJoystick.h`。產生程式只加入 `#include <TuKitJoystick.h>`、物件與使用呼叫，不再展開class定義。共同數位輸入支援隨每個專屬庫附帶，不需另外安裝第三方庫；Arduino與ESP32均可使用。
