# 溫度感測器 v1.2.0

只提供4個常用積木：初始化、讀取攝氏溫度、讀取類比值、讀取KY-028門檻狀態。直接讀取即可，不需要「更新狀態」。

編號可自行輸入0或正整數，例如8、42、100；相同模組在初始化與讀取積木填相同編號，沒有1～4限制。不同模組請用不同編號和實際接腳。

| 訊號 | Arduino 預設 | ESP32 預設 |
| --- | --- | --- |
| KY-013 S／KY-028 AO | A0 | GPIO15 |
| KY-028 DO（選接） | 可選D2，預設不接 | 可選GPIO23，預設不接 |
| 電源／GND | 依模組，通常5V／GND | 支援3.3V模組接3V3／GND |

~~~text
溫度模組（8）初始化 AO A0 DO 不接 觸發電位 高電位
重複無限次
  使用「溫度模組 8 KY-013 攝氏溫度 NTC 接 GND」
~~~

KY-013是NTC分壓電路，預設R0=10kΩ、B=3950、固定電阻10kΩ、標稱25°C。若NTC與固定電阻接法相反，請選NTC接VCC。開路、短路或無效參數回傳NaN。KY-028優先使用類比值／數位閾值；DO的觸發電位可選HIGH／LOW，電位器門檻不直接等於攝氏溫度。

類比值統一0～1023，初始化自動配合Arduino AVR的10bit或ESP32的12bit，不修改全域ADC解析度。舊專案的原始ADC與校準積木仍可載入，但不再放進工具箱。

資料：[Joy-IT KY-013](https://sensorkit.joy-it.net/en/sensors/ky-013)、[KY-028](https://sensorkit.joy-it.net/en/sensors/ky-028)。

## 接線要點

ESP32 訊號維持3.3V。預設GPIO15屬經典ESP32的ADC2，搭配Wi-Fi時請改用板卡可用的ADC1腳位。GPIO0／2／5／12／15涉及啟動設定，接線以實際板卡與模組絲印為準。
