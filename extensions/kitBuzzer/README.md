# 有源／無源蜂鳴器 v1.2.0

Arduino／ESP32共用。工具箱提供五個常用積木，不需要更新狀態。

1. **蜂鳴器（編號）初始化**：設定訊號腳、有源／無源類型及有源觸發電位。
2. **有源蜂鳴器（編號）開啟／關閉**：用於內建振盪器的KY-012。
3. **無源蜂鳴器（編號）播放音符**：預設中音Do，可選低／中／高音的Do、Re、Mi、Fa、Sol、La、Si及五個升半音。
4. **無源蜂鳴器（編號）播放頻率**：可直接輸入自訂Hz；不等待，頻率31～20000Hz，0表示停止。
5. **蜂鳴器（編號）停止**：兩種類型都適用。

音符選單使用第3／4／5八度；中音Do、Re、Mi、Fa、Sol、La、Si分別約為262、294、330、349、392、440、494Hz。選高音Do即523Hz。音符會持續發聲，演奏旋律時在音符之間加入等待積木控制節拍，最後放停止積木；播放積木本身不等待。

編號可直接輸入任意非負整數，例如0、8、42、100；同一顆模組使用相同編號。多顆使用不同編號與不同接腳。

| 接線 | Arduino預設 | ESP32預設 |
| --- | --- | --- |
| S／訊號 | D2 | GPIO23 |
| ＋／VCC（若有） | 依模組規格 | 依模組規格及3.3V邏輯相容性 |
| －／GND | GND | GND |

例如「蜂鳴器42初始化訊號23類型KY-006無源」，接著使用「無源蜂鳴器42播放440Hz」，最後用「蜂鳴器42停止」。

有源類型使用開關，無源類型使用頻率，兩種控制不混用。有源觸發電位對無源類型沒有作用。先確認模組絲印與供電，電流較大的蜂鳴器使用適當驅動電路。

同時只播放一個無源蜂鳴器，新播放會取代上一個；停止其他編號不會停掉目前的音。有源蜂鳴器可各自開關。ESP32 core 2.x／3.x的對應LEDC API已處理，並與本批RGB的PWM timer分開；與其他PWM／伺服函式庫共用時仍需確認硬體資源。Uno／Nano的tone可能影響D3／D11 PWM，本批RGB預設D5／D6／D9可避開這個常見衝突。

舊專案的發聲狀態／初始化狀態積木仍可載入，但不再列於工具箱。無第三方函式庫依賴。

資料：[KY-006](https://sensorkit.joy-it.net/en/sensors/ky-006)、[KY-012](https://sensorkit.joy-it.net/en/sensors/ky-012)。實物照片以600×372 SVG畫布等比例顯示，原圖與來源SHA256保留於 assets/SOURCES.json。

## 專屬函式庫

擴充附帶 `TuKitBuzzer`，產生的程式只會 `#include <TuKitBuzzer.h>`，再宣告物件與呼叫方法；class與硬體處理函式均在函式庫內。保留 `lib/TuKitBuzzer` 完整資料夾即可編譯，無額外第三方函式庫依賴。
